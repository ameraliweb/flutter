# حل النموذجين الخامس والسادس في Flutter

**اسم الطالب:** حسين محمد احمد عبدالله عبده

هذا المشروع يطبق المطلوب في النموذج الخامس والنموذج السادس من ملف التكليف:

- **النموذج الخامس:** زر حذف يعرض نافذة منبثقة للتأكيد، وشريط أفقي من أربعة أيقونات.
- **النموذج السادس:** ثلاث حاويات ممتدة أفقيًا بألوان مختلفة، وعداد يبدأ من 15 مع زري زيادة ونقصان.

## التشغيل

1. افتح مجلد المشروع في Android Studio أو VS Code.
2. تأكد من تثبيت Flutter.
3. نفّذ:

```bash
flutter pub get
flutter run
```

من الشريط السفلي يمكن الانتقال بين النموذج الخامس والنموذج السادس. التطبيق مضبوط باتجاه عربي من اليمين إلى اليسار، وكل الأزرار المطلوبة تفاعلية.

## الملفات المهمة

- `lib/main.dart`: جميع واجهات النموذجين والمنطق التفاعلي.
- `pubspec.yaml`: إعدادات مشروع Flutter.
